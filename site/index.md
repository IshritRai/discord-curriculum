# Build a Chat App: learn frontend development

You'll learn HTML, CSS, JavaScript and React by building a chat app that looks like Discord's desktop app, with servers, channels, messages, reactions, a member list, modals, right-click menus and a voice-channel interface. **All data is fake**: there is no backend, no real accounts and no networking. You build it twice: first with plain HTML, CSS and JavaScript, then again with React, so you can compare the two approaches.

The app uses a placeholder name ("Hubbub") and original icons. All branding lives in one file, `js/brand.js`, so you can change it later.

## How to use this site

1. Read a lesson in the browser, and **type the code yourself** in VS Code. Typed code has no copy button on purpose.
2. Code in a yellow **Starter code** box is different: you paste it, because you'd learn nothing from typing it. The box tells you which lesson explains it.
3. Each step ends with a collapsed **Reveal solution**. Try first, then look.
4. Finish with the **Checkpoint** and the **Quiz**, then make the suggested Git commit.
5. Click **Mark this lesson as complete**. Progress and quiz scores are saved in this browser (see [Your progress](./progress)).

## The route

| Phase | Lessons | What you build |
| --- | --- | --- |
| Setup | 00 | Tools, how the web works, DevTools |
| Git | 01 | Version control and GitHub |
| HTML | 02–03 | The semantic skeleton of the app |
| CSS | 04–11 | The dark theme, the four-column layout, hover states, scrolling and a responsive layout |
| JavaScript | 12–18 | Rendering from data, events, state, localStorage, modules, JSON |
| Features | 19–28 | Unread badges, message feed, markdown, sending, editing, reactions, modals, menus, fake activity |
| Voice | 29–30 | A voice-channel interface (UI only), plus an optional local microphone meter |
| Deploy | 31 | The plain version on GitHub Pages |
| React | 32–40 | The same app again, with components, state, effects and routing |
| Wrap-up | 41 | Vanilla vs React, and deploying React |

There are 42 lessons of about 45–60 minutes each (41 core lessons plus one optional). At six lessons a week that's about seven weeks. [The curriculum plan](https://github.com/IshritRai/discord-curriculum/blob/main/docs/CURRICULUM.md) explains why the lessons are in this order.

## Two rules the course follows

- **No untaught code.** You are only asked to type code that uses ideas from the current lesson or earlier ones. Everything else is clearly marked as pasted starter code. The [concept index](./concepts) lists every idea and the lesson that introduces it.
- **Every solution runs.** The course repository contains a working copy of the app at the end of every lesson, in `solutions/lesson-NN/`. If you get stuck, compare your folder with it, or copy it. Each was opened in a real browser and checked.

## Works on macOS, Windows and Linux

Use the **I use macOS / Windows / Linux** switch in the top bar. The site detects your system, remembers your choice, and shows the right keyboard shortcuts and install steps. On Windows the course uses **Git Bash** as the terminal, so every command is the same on all three systems.
