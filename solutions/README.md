# Reference solutions

`lesson-NN/` is a working snapshot of **your project folder at the end of lesson NN**. It's what your own repository should look like after you finish that lesson (apart from small differences in wording or spacing).

- **Compare:** open your folder and the snapshot side by side in VS Code (*Select for Compare* / *Compare with Selected* in the Explorer's right-click menu), or diff them in a terminal: `diff -ru your-folder solutions/lesson-07`.
- **Recover:** if you're stuck, copy the snapshot and continue from there.
- **Run it:** open `vanilla/index.html` of a snapshot with Live Server (Lessons 0–31), or run `npm install` and `npm run dev` inside `react-app/` (Lessons 32–41).

Lessons 0–31 contain `vanilla/` (the plain HTML, CSS and JavaScript app). From Lesson 32 on, snapshots contain `react-app/` and the files in the repository root; your own `vanilla/` folder stays as it was.

Every snapshot is opened in a real browser and checked by `npm run verify` in the course repository.
